# Singa Ticketing System — Landing page / UI design

A single-page marketing/landing design for a fictional IT helpdesk ticketing platform, built to
practise product UI and visual design.

## Highlights

- **Neon dark aesthetic** — deep-navy background with cyan and violet accents, ambient radial glows,
  and gradient headline text.
- **Dashboard mockup** — stat cards (open tickets, resolved today, average response, SLA compliance)
  and a live-styled ticket table with priority tags and glowing status dots.
- **Feature grid** — six product capabilities (real-time tracking, smart routing, SLA management,
  analytics, auto escalation, role-based access).
- **Responsive** — reflows cleanly from desktop to phone width.

## Tech

Plain HTML and CSS in one file (`index.html`), no build step and no JavaScript. Fonts: Inter and
JetBrains Mono from Google Fonts.

> This is a **static design concept**, not a working application. For the working, interactive
> ticketing app (QR tickets + door scanner), see the [`ticketing-system/`](../ticketing-system/) project.
